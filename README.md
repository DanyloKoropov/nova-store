# NovaStore

A responsive e-commerce application built with React.

## Features

- Product catalog
- Product details page
- Live search
- Category, price, and rating filters
- Product sorting
- Shopping cart
- Favorites
- LocalStorage persistence
- Checkout form
- Form validation
- Responsive design
- Loading, error, and empty states

## Technologies

- React
- React Router
- Context API
- JavaScript
- CSS
- DummyJSON API
- Vite

## Installation

```bash
npm install
npm run dev
